hero-placeholder.jpg — фоновая картинка hero-блока на главной странице
(под шапкой "Записная книжка поэта / Егор Андреев"). Сейчас файла нет,
показывается CSS-градиент (см. src/app/page.tsx). Как только сюда
положить файл с именем hero-placeholder.jpg — он подхватится
автоматически, ничего в коде менять не нужно.

Рекомендуемые пропорции: широкое, горизонтальное изображение (шире,
чем 16:9) — блок примерно 46% высоты экрана на всю ширину, картинка
обрезается по центру (object/background: cover). Внизу лежит тёмный
градиент-затемнение для читаемости белого текста поверх — учитывайте
это при выборе кадра (нижняя часть фото не должна быть визуально
перегружена мелкими деталями, читаемость текста важнее).
